# EvidenceCast AI Submission Package

This directory contains the final submission material for the Backblaze Generative Media Hackathon.

## Contents

- [`submission-status.md`](submission-status.md) — completed work, remaining blockers and owner-only actions.
- [`devpost-description.md`](devpost-description.md) — ready-to-paste Devpost project description.
- [`providers-and-models.md`](providers-and-models.md) — complete provider/model inventory and precise Genblaze/B2 explanation.
- [`demo-script.md`](demo-script.md) — timed script and screen plan for a sub-three-minute demonstration.
- [`public-verification-checklist.md`](public-verification-checklist.md) — automated and private-browser judge-access verification.

## Submission principle

The package distinguishes three categories clearly:

1. implemented provider integrations;
2. provider attempts and their exact validated outcomes; and
3. the completed reviewed local delivery marked `provider_generated: false`.

No provider failure is presented as a generated media success.
